The ceremony

Three steps. Both sides confirm.

The code is a shared fingerprint of this session, not a password. The identity cards are what make a relay visible.

01

Create and invite

Start a session. Share the one-time link in the call chat. The link expires quickly and is not the verification code.

02

See the same person

Both participants see each other’s name, assurance level and masked or full personal number. If the name is wrong, stop.

03

Compare and confirm

Read the code aloud. Each person independently confirms the code and the person. Only then is a receipt created.

What it proves

Account presence, together.

  • Both authenticated accounts joined the same session.
  • Both saw each other’s identity and assurance level.
  • Both independently confirmed within the time window.

What it does not prove

The call channel is still the call channel.

  • That the voice or video stream is unmodified.
  • That the device or account is not compromised.
  • That a group call has no unverified listener.
