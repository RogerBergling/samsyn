How it works

Two people. One short verification.

You share an invitation link, both join, read the same code aloud, and both confirm. It takes about a minute.

01

Share the link

Start a verification and copy the link. Send it to the person in the call chat, by SMS, or by email. The link works once and expires.

02

Both join

The other person opens the link and signs in. You will both see each other's name and the same code.

03

Read the code aloud

Read the 6 digits and 3 words on the call. Do not text or email the code; it must be compared live. Check that the name is the person you expected.

04

Both confirm

Each person presses Confirm. Only then is the verification complete and a receipt created.

What to share

Share the link, not the code.

  • Send the invitation link in the call chat, SMS, or email.
  • The link works once. Do not post it publicly.
  • The code is read aloud only after both of you have joined.

Who can hear the code

Anyone on the call can hear it.

  • The code is not a password. It is a short-lived check that you are in the same session.
  • Do not read it to someone who called you first, and do not post it.
  • In a group call, other people can hear it. The app cannot detect a silent listener. For sensitive calls, use a 1:1 call and check the name.

During the verification

What each person should do.

The person who starts

  1. Start a verification.
  2. Copy the invitation link and send it to the other person.
  3. Wait for them to join.
  4. Read the code aloud and press Confirm.

The person who joins

  1. Open the invitation link.
  2. Check the name of the person who invited you.
  3. Compare the code with them on the call.
  4. Press Confirm only if the name and code match.
If the name or code is wrong, stop. Press “Something is wrong” and do not continue the call based on this verification. Contact the person or company through a channel you already trust.
